## Deskripsi Proyek
Proyek ini merupakan hasil penelitian Tugas Akhir / Skripsi di S1 Teknologi Informasi Universitas Negeri Yogyakarta (UNY). Sistem dirancang untuk membantu tenaga medis dan dokter gigi dalam mendiagnosis titik kelainan gigi secara otomatis.

### Fitur Utama
- **Deteksi Otomatis:** Menggunakan model Faster R-CNN yang dilatih dengan dataset citra panoramik gigi.
- **Visual Bounding Box:** Menampilkan lokasi spesifik kelainan gigi beserta tingkat akurasi (confidence score).
- **Laporan Diagnosis:** Menghasilkan ringkasan hasil analisis yang dapat dicetak atau disimpan.
- **Antarmuka Web Modern:** Dibangun dengan React.js dan Tailwind CSS untuk responsivitas maksimal.
