## Deskripsi Proyek
Aplikasi portofolio statis tanpa server backend (Serverless Static) yang menawarkan kecepatan memuat data secara instan, keamanan 100%, dan kemudahan pemeliharaan melalui Markdown & JSON Content Collections.

### Fitur Utama
- **Zero JS Default:** Memanfaatkan Astro Island Architecture.
- **Interaktivitas React:** Filter proyek interaktif, PDF preview modal, dan smooth navigation.
- **Type-Safe Data:** Validasi skema data portofolio & sertifikat menggunakan Zod.
